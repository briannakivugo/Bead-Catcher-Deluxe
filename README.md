# Bead Gem Deluxe

An arcade-style physics and collision game built across multi-platform development frameworks to analyze variable reward states, escalating velocity, and responsive input boundaries. 
## 🚀 Development & Sponsorship
This project was engineered and finalized through dual selective summer development pathways:
* Northeastern University Summer Program: Fully funded scholarship recipient focusing on object-oriented architecture, coordinate systems, and physics loops.
* Girls Who Code (GWC) Pathway Program: Advanced pathway tracking creative coding, canvas rendering, and custom animation lifecycles.

* ## 💻 Tech Stack
* Languages: C#, JavaScript (ES6+)
* Frameworks & Engines: Unity 2D Engine, p5.js Library.

* ## ⚙️ Core Technical Architecture
* Dynamic Physics & Vector Scaling: Implemented escalating velocity vectors on down-falling assets (`Bead` class) to continuously ramp up difficulty intervals.

* * Variable Reward States: Programmed array-based color assignment matrices where different rendering hex-codes trigger specific numeric point-multipliers.
 
  * * Dynamic Input Boundaries: Engineered a responsive, shrinking player platform (`Basket` class) that continuously alters positional collision detection parameters, systematically elevating the player's mechanical processing thresholds.
